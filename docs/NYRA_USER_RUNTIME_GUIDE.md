# 月栖运行与控制指南

面向普通用户与开发者：如何知道角色在做什么、如何关闭、如何排查。

## 普通用户

### 角色会主动联系我吗？

打开栖机 → **设置 → 陪伴与主动行为**。

- **AI 自主生活** 关闭：不会主动找你、不自动日记/动态（你仍可主动开 Pop 聊天）。
- 预设：
  - **安静**：不主动。
  - **陪伴**：适度主动，有安静时段与每日上限。
  - **沉浸**：更多生活事件；可把情景剧/游戏经历写入关系记忆。

首次进入小手机会要求你选择一种模式，不会静默开启高频主动。

### 多久主动一次？

同页查看 **主动频率**、**每日上限**、**安静开始/结束**。活动中心也会显示「今日主动次数 / 上限」与安静时段。

### 会自动写什么？

分项开关：

- 主动找我
- 自动写日记
- 自动发布动态
- 纪念日主动行为
- 情景剧经历进入记忆
- 游戏经历进入记忆

### 现在有没有 Agent 在跑？

**设置 → 活动中心 → 正在运行的任务**，或 **任务中心** 审批/暂停/取消。

### 它读了哪些数据？改了什么？

活动中心 → 点开一条「最近活动」，可看：

- 触发原因
- 使用能力
- 读取资源
- 产生修改
- 是否调用模型
- 可否撤销

不会展示完整 Prompt、API Key 或内部堆栈。

### 怎样关闭？

1. 关 **AI 自主生活**（总开关），或  
2. 选 **安静模式**，或  
3. 只关某一分项。

助手任务：关 **设置 → Agent 权限 → 允许栖机助手执行受控任务**。

### 怎样撤销？

活动详情会标明是否可撤销。任务产物一般在任务中心拒绝/取消；记忆类条目可在记忆/上下文相关界面处理（不可自动撤销的会写明）。

## 开发者

开启诊断页（不会出现在默认导航）：

```js
localStorage.setItem("yueqi.developerMode", "1");
```

然后：设置 → 高级 → **开发者诊断**。

可查看 / 操作：

| 问题 | 位置 |
|---|---|
| OpenClaw 是否已加载？ | 诊断 JSON：`openClawSliceLoaded` |
| 当前任务？ | 活动中心 + 任务中心；助手任务键 `yueqi.assist.agent.tasks.v1` |
| 下次事件？ | 诊断 / 活动中心 `nextWakeAt`；生活态 `yueqi.companion.life.v1` |
| 为何触发？ | 活动日志 `yueqi.activity.center.v1` |
| 工具？ | 任务流与 `yueqi.assist.audit.v1` |
| 状态存哪？ | 自主：`yueqi.autonomy.v1`；Agent：`yueqi.agent.prefs.v1` |

诊断操作：模拟时间经过、触发主动事件、写入测试活动、导出脱敏 JSON。

验证：`npm run verify:feature-control`

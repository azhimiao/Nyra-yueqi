# 星澈桌宠角色资产计划（日系帅哥 → 微缩 → 动作）

> 目标：做出「好看、统一、可右键切姿势」的二次元男孩桌宠素材。  
> 原则：**先定人，再定比例，再定妆，最后才出动作**。禁止用异性参考图硬转。

---

## 0. 一句话目标

从零设计一个日系帅哥「星澈」，用**三视图 + 头身比**锁死形象；再微缩成桌宠比例；再用定妆图迭代全部动作；最后透明 PNG 接入月栖桌宠 / 悬浮窗。

---

## 1. 为什么分阶段（不要一步出动作）

| 错误做法 | 正确做法 |
|----------|----------|
| 用女孩图改性别 | 从零 T2I 出男生 |
| 直接出 idle/sleep/greet | 先三视图，再微缩，再定妆，再动作 |
| 每张动作重新描述外貌 | 所有动作只改 pose，身份锁定同一张定妆 |
| 比例口头随便说 | 写死数字：帅哥立绘 / 桌宠头身比 |
| 粉底带装饰当成品 | 必须透明底、可叠加桌面 |

---

## 2. 角色圣经（Character Bible）

出图前先冻结下面字段；之后任何步骤不得改（除非你主动改设定）。

### 2.1 身份

- 名字：星澈（Xingche）
- 性别：男
- 气质：日系帅哥 / 少年感，干净、温柔、略潮，不要幼齿娃娃脸，不要写实照片脸


### 2.3 画风

- 日系二次元插画 / 精细线稿 + 赛璐璐或软阴影
- 禁止：写实、3D、厚涂油画、异性化、贴纸粉红爱心堆砌（除非你明确要 kawaii sticker）
- 背景：纯色或纯白，便于抠图；成品必须透明底

### 2.4 头身比（硬约束）

| 阶段 | 头身比 | 用途 |
|------|--------|------|
| A. 帅哥立绘 | **7～7.5 头身** | 定五官、服装、三视图 |
| B. 桌宠微缩 | **3 头身**（可接受 2.8～3.2） | 桌宠实际显示 |
| C. 动作迭代 | **锁定与 B 完全一致** | 所有姿势 |

验收口诀：A 要「帅」，B 要「缩得像同一人」，C 要「只变姿势不变人」。

## 3. 资产流水线（四步）

```
[1] T2I 帅哥三视图 (7.5头)
        ↓ 人选满意才继续
[2] I2I 微缩三视图 (3头) —— 同一人、同一服装
        ↓ 人选满意才继续
[3] I2I 定妆单立绘 idle —— 从微缩三视图抽出正面待机
        ↓ 人选满意，锁成 Character Lock
[4] I2I 动作迭代 —— 每张只改 pose，引用 Lock
        ↓
[5] 抠透明底 → 缩放 → 接入 public/assets/pet-poses/
```

### 3.1 Step 1 — 帅哥三视图（Turnaround）

**产出**：一张图内 **正面 / 侧面 / 背面** 三视图  
**文件建议**：`_sheet_handsome.png`

要求：

- 同一身高对齐，正面、侧面、背面并排
- 7～7.5 头身
- 服装细节前后一致（拉链、口袋、鞋、背带）
- 无文字、无水印、无复杂场景

**过关标准**：你愿意拿这张当「这个角色就是他」——不过关就只重做 Step 1，禁止往下走。

### 3.2 Step 2 — 微缩三视图

**产出**：同构图的三头身三视图  
**文件建议**：`_sheet_chibi.png`

要求：

- **身份锁死**：脸、发型、服装、配色与 Step 1 同一人
- **只改比例**到 3 头身
- 仍是男孩帅哥感，不要缩成婴儿脸

**过关标准**：并排对比 Step1 / Step2，一眼能认是同一个人。

### 3.3 Step 3 — 定妆待机锁（Character Lock）

**产出**：单人正面全身待机  
**文件建议**：`idle_default.png` + `_character-lock.png`（副本）

姿态建议：站立、双手插兜或自然下垂、正视镜头、平静微笑。

**过关标准**：这张将成为之后所有动作的唯一参考；不满意只重做 Step 3。

### 3.4 Step 4 — 动作迭代

每张动作：**同一 Lock 图生图**，prompt 只写姿势差，不重写外貌。

#### 必做（右键菜单 MVP）

| ID | 名称 | 姿势要点 |
|----|------|----------|
| `idle_default` | 待机 | 正面站立，放松 |
| `sleep_pose` | 睡觉 | 侧卧/蜷睡，闭眼 |
| `greet` | 打招呼 | 站立挥手 |
| `selfie` | 自拍 | 举手机 + 比耶 |

#### 建议补

| ID | 名称 | 姿势要点 |
|----|------|----------|
| `talking_default` | 说话 | 微张嘴，手势聊天 |
| `react_tap` | 点击回应 | 吃惊/害羞跳一下 |
| `comfort` | 安慰 | 温柔伸手/拥抱感 |

**过关标准**：把 7 张缩略图排成一行，五官发型服装无漂移。

### 3.5 Step 5 — 工程交付

1. 抠透明底（去白/浅粉底）
2. 长边缩到约 **768px**（桌宠够用，体积可控）
3. 落到：`public/assets/pet-poses/{actionId}.png`
4. 应用已支持：无用户绑定素材时，自动用这些默认姿势

---

## 4. 质量门槛（这次失败要避开的）

人工验收 checklist：

- [ ] 帅：不是幼齿、不是「可爱到丑」、不是异性化
- [ ] 统一：动作之间发型/眼睛/衣服不漂
- [ ] 比例：桌宠稳定三头身，不忽高忽矮
- [ ] 手部：无明显残肢、六指（不过关就重出该张）
- [ ] 透明：桌面上看不到色块底板
- [ ] 风格：日系插画，不是贴纸粉红堆、不是写实

**模型策略建议**（可换，不绑定）：

- 当前脚本默认：火山方舟 `doubao-seedream-4-5`
- 若质量不够：换更强的角色一致性模型 / 人工修图 / 委托画师出三视图+定妆，AI 只做动作变体
- **禁止**再用异性图当 style ref

## 5. 工程接入（代码侧，已具备能力）

| 能力 | 说明 |
|------|------|
| 动作目录 | `idle_default` / `sleep_pose` / `greet` / `selfie` / … |
| 默认资源路径 | `public/assets/pet-poses/*.png` |
| 回退逻辑 | 用户未绑定 `mediaId` → 用默认姿势图 |
| 桌宠右键 | 打招呼 / 自拍 / 睡觉 / 回待机 |
| 渲染优先级 | 动作图 > 外表图 > 程序化男孩 |

生成脚本（可选工具，不是必须用）：

```bash
# 需本地 .env 里配置 ARK_API_KEY
node scripts/generate-pet-poses.mjs --from sheet   # 从三视图整链
node scripts/generate-pet-poses.mjs --from chibi   # 从微缩重做
node scripts/generate-pet-poses.mjs --from lock    # 只重做动作
node scripts/knockout-pet-pose-bg.mjs              # 抠透明 + 缩放
```

人工交付时：直接替换 `public/assets/pet-poses/` 下同名 PNG 即可，不必跑脚本。

## 6. 推荐执行节奏（给你自己或画师）

### Phase A — 定人（1～3 天）

1. 出 3～5 版帅哥三视图，你只挑 1 版
2. 冻结 Character Bible（发型/服装是否改）

### Phase B — 微缩（半天）

1. 同人三头身三视图
2. 抽出定妆 idle，锁死

### Phase C — 动作（1 天）

1. 先出 4 张必做，右键验收
2. 再补 talking / react / comfort

### Phase D — 接入验收

```bash
npm run desktop:dev
```

右键切换姿势；角色页舞台也应显示同一套图。

# 本地聊天助手

> 月栖栖机可选能力（F7 · H6）。**默认关闭**，不出现在默认桌面。

## 它是什么

「本地聊天助手」帮助你把**本机已有的文本**导入为 Pop 聊天草稿，方便继续与角色对话。它是月栖自研的轻量桥接面板，**不对接任何外部聊天服务的官方接口**，也不读取其它应用的私有数据库。

## 支持的路径

1. **手动粘贴**（推荐）：在设置 → 本地聊天助手 → 桥接面板中粘贴文本 → 预览 →「导入为 Pop 草稿」。草稿写入输入框，**不会自动发送**。
2. **剪贴板**：你可先在其它地方复制文本，再回到桥接面板粘贴（同上）。
3. **文件内容手动导入**：将纯文本复制后粘贴导入（不自动监视文件夹）。

## 不支持的路径

- 自动读写其它应用的私有存储、会话库或缓存
- Hook / 注入其它进程
- 需要 root / 越狱的能力
- 远程拉取第三方聊天服务消息
- 把导入内容当作已发送消息（导入仅为草稿）

## 如何开启

1. 打开栖机 → **设置**
2. 在「扩展与栖市」中打开 **实验 · 桥接面板**
3. 出现「本地聊天助手」分组后，可使用桥接面板导入草稿

关闭后，设置中不再显示「本地聊天助手」入口；桌面不会出现独立图标。

## 隐私与风险

- 粘贴内容仅保存在你本机当前会话的输入草稿中，除非你主动发送。
- 请勿粘贴他人隐私、密钥或无权转发的内容。
- 云门禁 / 云同步与本助手无关；本助手默认完全本地。

# 星梨桌宠：完整提示词流程（可自测手册）

来源：`F:/beautiful/scripts/generate-xingli-assets.mjs`（**以脚本为准**；旧 SPEC 里部分「5.5～6 头身 / 洋红底」已被脚本纠正为 **4.8 头身 + 灰底 #B8B8B8**）。

画布：`1536×1536`  
模型建议：`doubao-seedream-5-0-pro`（或你可用的 Seedream），图生图必须带参考图。

---

## 0. 总流程（不要跳）

```text
① 出 3 张锁图候选（纯文生图，灰底）
② 你人眼选 1 张「够可爱、手脚正常」→ 冻结为 character_lock.png
③ 每动作 1～2 张关键姿势（图生图，必须上传 lock；部分还上传上一帧）
④ 本地：灰底抠图 rembg isnet-anime → RGBA（不要信模型「透明」）
⑤ talk 等循环帧做配准；废图只重做该动作
⑥ 再拼 atlas / 进播放器（脚本可做；你手测可先只做到 ④）
```

**禁止：** 每帧独立文生图凑 116 张；未锁图就批量出动作；把棋盘格当透明。

## 2. 锁图提示词（拼装公式）

脚本公式（用 `。` 连接）：

```text
{CHARACTER_BIBLE}。
这是三张候选中的第{N}张；{LOCK_VARIANTS[N-1]}。
如果提供了参考图，只参考其中的可爱比例、脸部气质、发型配色和服装语言；不要复制棋盘格背景，不要生成三视图，重新绘制一张单人正面全身定妆图。
用途是透明悬浮桌宠的唯一角色定妆锁图；保持22岁成年设定、年轻可爱的恋人感和稳定4.8头身。
{IMAGE_RULES}。
{NEGATIVE_RULES}。
```

### LOCK_VARIANTS（三选一气质）

1. `气质年轻甜美、软萌亲近，双手自然垂在身体两侧，轻柔闭嘴微笑，目光直视用户；可爱度优先，脸部必须短圆而精致，但保持22岁成年设定`
2. `气质偏亲近明快，一只手轻放在胸前，另一只手自然垂下，带有克制而甜美的微笑`
3. `气质偏成熟优雅，双手在身前自然轻握，神情柔和可靠，站姿放松但不幼态`

**锁图人工验收：** 够不够可爱；4.8 头不是 5.5 御姐；双手双脚正常；无棋盘/乱码字；全身入镜。不过就重出，别进动作。

## 3. 动作关键姿势提示词（拼装公式）

上传参考：

- 默认：`refs: [lock]` → 只上传 `character_lock.png`（图一）
- `talk_1`：上传 lock + `talk_0`（图一锁、图二上一帧）
- `sit_to_sleep_mid`：上传 lock + `sit`
- `greet_1` / `react_1`：上传 lock + 同动作第 0 帧

公式：

```text
{referenceNote}。
{CHARACTER_BIBLE}。
动作要求：{motion}。
必须保持参考图的脸型、发型、发色、瞳色、成年体型、头身比、服装、腰带、鞋、线稿、配色和光源完全一致；只改变动作中明确指定的姿势和表情。
{poseEditingRule}。
保持与定妆图一致的人物视觉尺寸和身体体积；站姿脚底基线稳定，坐卧姿势与悬浮窗底边形成可信的隐形支撑关系，动作转换前后重心连续。
{IMAGE_RULES}。
{NEGATIVE_RULES}。
```

其中：

- `referenceNote`  
  - 单参考：`参考图是不可改变身份的唯一角色定妆锁。`  
  - 多参考：`图一是不可改变身份的定妆锁；其余参考图只用于动作连续性。`
- `poseEditingRule`  
  - 普通动作：`参考图只用于锁定角色身份、服装与动作端点；不得机械复制端点姿势，必须按目标动作重新绘制自然完整的双手和双脚，五指自然、关节清楚，双腿和鞋之间保留清晰间隙`  
  - `talk_1`（lockPose）：`图二是必须逐像素级贴近的动作上一帧；保持其角色外轮廓、全身姿势、比例、尺寸、位置和基线，只修改动作要求明确允许的局部表情`

## 5. 手测最短路径（建议）

1. 只做 **锁图候选 1**（文生图 + 灰底整段锁图 prompt）  
2. 你觉得可爱 → 再做 **comfort**（I2I + lock，最容易翻车的动作之一）  
3. 再做 **talk_0 → talk_1**（测连贯；talk_1 必须贴上一帧）  
4. 每张用 rembg `isnet-anime` 抠灰底；检查：多手？棋盘？脚底漂？  

批量可用仓库命令（密钥只放环境变量）：

```powershell
cd F:\beautiful
$env:ARK_API_KEY = "<你的方舟key>"
$env:ARK_IMAGE_MODEL = "doubao-seedream-5-0-pro-260628"
npm run generate:xingli -- --stage lock
# 人选 N 后：
npm run generate:xingli -- --stage poses --select N
```

也可只跑单个动作：`--only comfort` / `--only talk_0,talk_1`。

## 6. 返修规则（会话血泪）

| 现象 | 处理 |
|------|------|
| 太成熟 / 长脸 | 整张锁图作废重出，不进动作 |
| comfort 伸手怼镜头 | 重做；prompt 已写死「手胸口」 |
| talk 两帧缩放跳 | talk_1 用 lockPose 文案 + 本地 registerTo talk_0 |
| sleep 有地影 | 重做 + 后处理去影；prompt 禁地面投影 |
| 多手/残肢 | **HARD 打回**，不凑合进包 |
| 棋盘假透明 | 灰底重生 + 本地抠图，勿要模型透明 |

失败只重做该动作，禁止整包重烧。

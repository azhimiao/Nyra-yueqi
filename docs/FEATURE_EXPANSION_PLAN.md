# 月栖 · 功能扩展计划（v1.0 之后）

> 品牌：**月栖**（英文 **Nyra**）  
> 原则：本地优先、授权可控、可备份可迁移  
> 日期：2026-07-18  
> 关联：[PRODUCT_ROADMAP](./PRODUCT_ROADMAP.md) · [FEATURES_COMPANION_PRESENCE](./FEATURES_COMPANION_PRESENCE.md) · [IMPLEMENTATION_PLAN](./IMPLEMENTATION_PLAN.md) · [LIVING_PHONE_PLAN](./LIVING_PHONE_PLAN.md)（栖机世界 / 阶段 Prompt）

---

## 0. 现状一句话

**v1.0 核心陪伴闭环已落地**（聊天 / 记忆宫殿 / 日记 / 主动消息 / 日历 / 生活库 / 语音 / 主题 / 安全加固 / 中英门禁）。  
本计划只排 **v1.0 之后的扩展**，不再复述已完成的 P3–P7。

自动化基线：`npm run verify`（含 companion-presence / i18n / security）。

---

## 1. 扩展原则

| 原则 | 含义 |
|------|------|
| 月栖自己的产品语言 | 不做「对标某竞品」叙事；能力以陪伴体验命名 |
| 先加深已有页 | 优先聊天 / 生活 / 设定已承诺但未做深的点 |
| 占位仍不排期 | **世界**、**衣橱 / Live2D** 等产品定义后再立项 |
| 可验收再开工 | 每波有验收标准 + `verify:*` 或手测清单 |
| 小步垂直切片 | 一次交付一条用户可感知路径，避免大重构与功能混做 |

---

## 2. 扩展波次总览

```
X1  陪伴临场加深     同步听 · 通话流式（Presence E）  ✅
X2  品牌与语言       全站 i18n · 文案诚实化 · Nyra/月栖一致  ✅
X3  聊天体验打磨     能力状态条 · 状态联动 · 摘要多段  ✅
X4  生活库加深       共读进度 · 听歌上下文 · 相册回忆对话  ✅
X5  工程与交付       app.js 拆分 · 包体积 · 原生密钥加固  ✅
──  远期（不排期）   世界平台 · Avatar / Live2D / 换装
```

建议默认顺序：**X1–X5 均已完成**；后续以产品定义驱动「世界 / Avatar」远期项。

---

## 3. X1 · 陪伴临场加深（Presence E）

**目标：** 从「单人本地陪听 / 截帧通话」进到「更像在一起」的同步感。  
**文档：** [FEATURES_COMPANION_PRESENCE](./FEATURES_COMPANION_PRESENCE.md) 阶段 E

| Step | 交付 | 验收 |
|------|------|------|
| X1-1 | **同步听协议（本地）**：共听状态含曲目、进度、播放/暂停；写入 prompt + 聊天系统条 | ✅ |
| X1-2 | **同步听 UI**：进度条共享展示、一键「把进度告诉 TA」 | ✅ |
| X1-3 | **视频通话流式回复**：截帧后流式打字 + 可选 TTS | ✅ |
| X1-4 | **通话会话记忆**：挂断后摘要入库（`source: call.session`） | ✅ |
| X1-5 | **双端同步听**：本机多标签 BroadcastChannel 同步进度 | ✅ |

**不做：** 公网随机匹配、第三方直播 SDK（除非产品另立）。

**建议工期：** 1.5–2.5 周

## 4. X2 · 品牌与语言

**目标：** 英文用户完整可用；中文永远是「月栖」，英文永远是「Nyra」。

| Step | 交付 | 验收 |
|------|------|------|
| X2-1 | 语言包覆盖：设定 / 接口 / 日记 / 日历 / 生活主文案 | ✅ |
| X2-2 | 运行时字符串走 `t()`：`app.js` 高频 `alert` / 状态文案 | ✅ |
| X2-3 | 备份 / 导出元数据带 `locale` + `brand` | ✅ |
| X2-4 | 文案去占位角色名；统一「角色来自人物卡」 | ✅ |

**自动化：** `npm run verify:x2`（并入 `npm run verify`）

**建议工期：** 1–2 周

## 10. 开工方式

对话里直接说：

- `执行扩展 X1` 或 `执行 X1-1`
- `执行扩展 X2`
- 或指定：「先做能力状态条」（落在 X3-1）

每完成一个 Step：更新本文件对应行状态为 ✅，并补 `verify:*`（若适用）。

# 角色包定制交付检查清单（Phase 3）

手工交付前，在角色页点「运行交付检查」，并确认本表。

## 必交付物

| 项 | 说明 |
|----|------|
| 角色包 ZIP | `manifest` + looks + actions + expressions + scenes + 素材 |
| 动作包 ZIP（可选） | 仅动作/表情增量，可叠到已有角色 |
| 版本号 | `packMeta.version`，升级可回滚 |
| 必需动作 | `idle_default`、`talking_default`、`comfort` |
| 至少一个带素材外表 | PNG/WebP 透明立绘 |
| proactive 场景 | 主动消息可触发安慰/对应动作 |

## 验收句

> 不改 App 代码，仅导入角色包/动作包，即可在 Web、Android 悬浮、Windows 桌宠上看到新外表与待机/说话/安慰动作。

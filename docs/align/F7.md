## 1. 本波目标（用户可感知一句话）

栖机可以像真手机一样「装 App」：从栖市安装扩展、桌面出现图标、点开在沙箱里跑；权限要授权才给；合规门禁和成年审核可关；举报有本地队列；本地聊天助手默认不出现，按文档可选开。

## 4. 产品语义（月栖用语，交互长什么样）

### 4.1 栖市（H1）

**入口：** 栖机桌面第 2 页新增图标 **栖市**（`id: qishi`，主色 `#6B9080` 薄绿，Lucide `store`）。

**列表页：**
- 顶栏：返回桌面 + 标题「栖市」+ 右侧「侧载」文字按钮（打开 `.yueqi-ext.zip` 文件选择）。
- 首屏 Segmented：**已安装** | **发现**（发现仅在 `cloudCatalogEnabled` 为 true 时出现；默认隐藏该 Tab，侧载仍可用）。
- **已安装：** 卡片行 — 48px 圆角图标、扩展名、版本号、状态 pill（运行中 / 已停用 / 待授权）；左滑或长按出「卸载」「权限」。
- **发现（可选）：** 远程 manifest 拉取后的卡片网格；每卡封面图（或统一插画占位）、名称、一句话简介、年龄标签（全龄 / 需成年确认）。
- **空态：** 插画 +「还没有扩展」+ 主按钮「从本机安装包添加」。

**详情页：**
- 大图头区（扩展 icon 128px）、名称、作者、版本、权限摘要列表（图标 + 中文权限名，最多展示 5 条 +「共 N 项」）。
- 主按钮：**安装** / **打开** / **更新**（三态）；次按钮「权限管理」。
- 底部文字链「举报此扩展」→ 跳转举报表单（H5）。
- 若 H4 开启且扩展 `contentRating === "mature"` 且用户未过成年审核：主按钮禁用，副文案「需先完成成年确认」链到设置。

**安装流程反馈：**
- 选 zip → 全屏轻遮罩 +「正在校验…」→ 成功 toast「已添加到栖市」+ 询问「添加到桌面？」→ 确认后在 `iconOrder` 写入 `ext:<extId>` 空槽。
- 校验失败：错态卡片（U7）— 原因人话化（「缺少 manifest」「权限未声明」「版本过低」）+「重选文件」。

### 4.2 扩展运行时（H2）

**桌面：** 已装且启用的扩展在网格显示与内置 App 同规格的 `mini-app-icon`；`data-app-id="ext:sample-calendar"`。

**扩展壳页：**
- 标准 `mini-appbar`：返回 + 扩展名 + 可选「⋯」菜单（权限 / 举报 / 关于）。
- 内容区 iframe 或 shadow DOM 沙箱（禁止 `parent` 逃逸）；加载中 skeleton（U6）；崩溃错态「扩展未能启动」+ 重试 / 卸载。

**权限弹窗（首次 + 按需）：**
- 底部 sheet：扩展 icon、请求权限中文名与一句说明、勾选「记住选择」、按钮「允许」「拒绝」。
- 拒绝后扩展 API 抛 `PermissionDeniedError`；样例扩展须 catch 并在页内显示「需要日历读取权限才能显示日程」+ 按钮「去授权」。

**样例扩展「日程信物助手」（`sample-calendar-token`）：**
- 上半：今日 / 明日日程列表（读 Host `calendar.listEvents`）。
- 下半：按钮「发送今日提醒信物」→ 调 `chat.sendTokenCard({ kind: "reminder", title, subtitle })` → 成功 toast + 可选跳转 Pop。
- 未授权日历时：空态 + 去授权；未授权信物发送时：inline 错态。

### 4.3 账号与门禁（H3）

**入口：** 设置 → 分组「账号与门禁」（在「系统与账号」屏内新增 section，不另开 App）。

**本地模式（默认开）：**
- 大号 switch「本地模式」说明：「不登录也可使用栖市与扩展；云门禁关闭。」
- 开：隐藏登录表单；栖市 / 扩展 / 举报全本地。

**云门禁（默认关，依赖本地模式关）：**
- switch「云门禁」+ 输入框「服务地址」（placeholder `https://your-gate.example`）。
- 开：显示占位登录（邮箱 + 验证码 mock）；登录成功写 `gateSessionToken` 到 secure-store。
- 未登录且云门禁开：进入栖市「发现」Tab 时显示「请先登录」+ 去登录。

### 4.4 成年审核（H4）

**入口：** 设置 →「合规与年龄」。

- switch「启用成年确认门槛」（默认关）。
- 开：显示出生年 `<select>` 或四位数字输入 + 复选框「我确认已年满 18 周岁」+ 保存。
- 校验：`birthYear <= currentYear - 18` 且勾选为真 → `ageVerified: true`。
- 栖市安装 `contentRating: "mature"` 扩展前检查；未通过则详情页禁用安装（见 4.1）。

### 4.5 举报与内容管理（H5）

**入口：** 栖市详情 / 扩展运行页「⋯」→ 举报；设置 →「内容与举报」→ 举报队列。

**举报表单：**
- 原因单选：垃圾信息 / 侵权 / 不当内容 / 其它；补充说明 textarea（可选）；截图附件可选（走 media 层）。
- 提交 → 本地队列 + toast「已收到，我们会尽快处理」。

**队列页：**
- 列表行：扩展名、原因、时间、状态（待处理 / 已读）；点进详情可看全文；左滑标记已读。
- 云同步开且有 endpoint：后台 POST，失败保留本地并显示「待同步」badge。

### 4.6 本地聊天助手（H6，可选）

**默认：** `localChatAssistantEnabled: false` — 设置内无入口。

**开启后：** 设置 →「本地聊天助手」→ 说明页（步骤列表 + 风险提示）+ 开关「启用桥接面板」。
- 桥接面板：手动粘贴文本 → 预览 →「导入为 Pop 草稿」（写入 composer，不自动发送）。
- 文档 `docs/LOCAL_CHAT_ASSISTANT.md` 写清支持的路径与不支持的路径；全文不出现外部 IM 品牌名。

### 5.1 存储键与 IndexedDB

| 键 / Store | 路径 | 说明 |
|------------|------|------|
| `yueqi.phone.extensions.v1` | localStorage | 已装扩展 registry（见 5.2） |
| `yueqi.phone.gate.v1` | localStorage | H3/H4 偏好（见 5.5） |

### 5.2 扩展安装包格式（`.yueqi-ext.zip`）

ZIP 内必须含根级 `manifest.json`：

```typescript
/** @typedef {object} PhoneExtManifest */
{
  schemaVersion: 1;                    // 固定 1
  kind: "yueqi-phone-ext";             // 必填，其它 kind 拒绝
  id: string;                          // ^[a-z][a-z0-9-]{2,48}$ 全局唯一
  name: string;                        // 1–32 字，展示名
  version: string;                     // semver x.y.z
  author?: string;
  description?: string;                // ≤ 200 字
  contentRating: "general" | "mature"; // H4 用
  entry: string;                       // 相对路径，默认 "index.html"
  icon?: string;                       // 相对路径 PNG/SVG，≤ 256KB
  permissions: PermissionId[];         // 声明权限，运行时可请求子集
  minHostVersion?: string;             // 对照 APP_VERSION
}
```

**校验失败降级：** 返回 `{ ok: false, code: "missing_manifest" | "invalid_kind" | "bad_id" | "bad_permissions" | "entry_missing", message: string }`，不写入 registry。

**Registry 条目 `InstalledExtension`：**

```typescript
{
  id: string;                          // manifest.id
  manifest: PhoneExtManifest;            // 安装时快照
  installedAt: string;                   // ISO8601
  updatedAt: string;
  enabled: boolean;                    // 默认 true
  grantedPermissions: PermissionId[];  // 用户已授
  iconDataUrl?: string;                // 侧载 icon 转 data URL 缓存
  source: "sideload" | "cloud";
  packageSha256?: string;              // 可选完整性
}
```

### 5.3 权限枚举（完整表，实现与 verify 必须一致）

| `PermissionId` | 中文名 | Host API | 说明 |
|----------------|--------|----------|------|
| `calendar.read` | 读取日历 | `host.calendar.listEvents(opts?)` | 读 `phone-data.listEvents()`，只读 |
| `calendar.write` | 写入日历 | `host.calendar.addEvent(payload)` | 调 `phone-data.addEvent`，需校验 normalizeEvent |
| `chat.read` | 读取聊天摘要 | `host.chat.getRecentMessages(opts?)` | 最近 N 条脱敏摘要，无 API key 仍可读本地 |
| `chat.send` | 发送文本消息 | `host.chat.sendMessage({ text })` | 桥接 `mountSmallPhone` 的 `sendMessage` |
| `chat.send_token` | 发送信物消息 | `host.chat.sendTokenCard(payload)` | 见 5.4；无权限时 U7 提示 |
| `storage.read` | 读扩展存储 | `host.storage.get(key)` | 命名空间 `ext:<id>:` |
| `storage.write` | 写扩展存储 | `host.storage.set(key, value)` | JSON 可序列化值，单 key ≤ 64KB |
| `notification.show` | 显示通知 | `host.notification.show({ title, body })` | 尊重 DND；拒权降级 toast |
| `timeline.write` | 写入同栖时间线 | `host.timeline.append(event)` | 写 F0 时间线 store，`appId: phone-ext:<id>` |
| `profile.read` | 读取角色摘要 | `host.profile.getActiveSummary()` | 仅 id / 显示名 / 头像 URL，无 prompt 全文 |

**拒绝时错误形状：**

```typescript
{ name: "PermissionDeniedError", permissionId: PermissionId, message: "需要「读取日历」权限才能继续" }
```

**`requestPermission(permissionId)` 流程：** 查 `grantedPermissions` → 有则 resolve → 无则弹 sheet → 允许则 push 并 persist → 拒绝则 throw。

### 5.4 信物消息卡 payload（样例扩展用）

```typescript
/** @typedef {object} TokenCardPayload */
{
  kind: "reminder" | "redpacket" | "transfer";  // 样例用 reminder
  title: string;       // ≤ 40
  subtitle?: string;   // ≤ 80
  amount?: number;     // redpacket/transfer 时用，单位分
  sessionId?: string;  // 默认当前会话
}
```

Host 将其转为 Pop 结构化气泡（F1 信物消息形态；若 F1 未落地则本波最小实现：`type: "token_card"` 的 message record + 气泡 UI 占位，但须像真卡 U10）。

### 5.5 门禁与成年审核 prefs（`yueqi.phone.gate.v1`）

```typescript
{
  localMode: true;              // 默认 true
  cloudGateEnabled: false;      // 默认 false
  cloudGateEndpoint: string;    // 默认 ""
  gateSessionToken: string;     // 默认 ""，敏感字段备份时可选 redact
  ageGateEnabled: false;        // 默认 false
  birthYear: number | null;
  ageVerified: boolean;         // 默认 false
  cloudCatalogEnabled: false;   // 栖市发现 Tab，默认 false
  cloudCatalogEndpoint: string;
  reportSyncEnabled: false;
  reportSyncEndpoint: string;
  localChatAssistantEnabled: false;
}
```

  detail: string;
  mediaId?: string;

### 5.7 样例扩展包（仓库内置）

路径：`public/extensions/sample-calendar-token/`（开发源）+ 构建产出 `public/extensions/sample-calendar-token.yueqi-ext.zip`。

- `manifest.json`：`id: "sample-calendar-token"`，`permissions: ["calendar.read", "chat.send_token"]`
- `index.html` + `app.js`：纯静态，通过 `window.nyra.host` 调 API

## 8. 分步实现顺序

1. **协议 + 权限表** — `manifest-schema.js`、权限枚举、错误类、样例 fixture；挂 verify 骨架。
2. **Registry + package-io** — 侧载 zip → 校验 → `InstalledExtension` 持久化；卸载清理 icon 槽。
3. **Host API + permission-ui** — 门控与 `requestPermission`；日历 / 信物 / storage 最小实现。
4. **扩展 runtime + 样例包** — shadow/iframe 加载 `sample-calendar-token`；桌面 `ext:*` 解析。
5. **栖市 UI** — 列表 / 详情 / 侧载 / 安装态；可选 cloud-catalog（默认关）。
6. **gate-prefs + gate-ui** — H3 本地模式默认开、H4 成年审核、设置 section。
7. **report-store + 举报 UI** — 表单 + 队列；云 sync 分支可 stub。
8. **H6 文档 + 可选面板** — `LOCAL_CHAT_ASSISTANT.md` + 设置开关默认 false。
9. **备份模块 + apps-catalog 对接** — 导出 / 恢复 extensions & gatePrefs & reports。
10. **`verify:align-f7` 补全断言** — 见 §9.3；`npm run verify:align-f7` 绿。

### 9.1 本波功能手测（路径级，必须可逐步照做）

**前置：** 冷启动栖机；设置 → 确认「本地模式」为开、「云门禁」「发现目录」「举报云同步」「本地聊天助手」均为关；日历里至少有 1 条今日日程（可用默认 seed）。

1. **侧载样例扩展**  
   打开 **栖市** →「从本机安装包添加」→ 选 `sample-calendar-token.yueqi-ext.zip` → 期望校验成功 → 详情显示权限「读取日历」「发送信物消息」→ 点安装 → 询问添加桌面 → 确认后第 2 页出现样例图标。

2. **读日历（已授权）**  
   点开样例扩展 → 弹出权限 sheet → 允许「读取日历」→ 列表显示今日日程标题与时间 → 与日历 App 一致。

3. **信物发送**  
   点「发送今日提醒信物」→ 若未授 `chat.send_token` 则先授权 → 成功 toast → 打开 Pop 可见结构化信物气泡（非纯文本 `[token]`）。

4. **权限拒绝**  
   设置 → 扩展权限 → 撤销「读取日历」→ 再打开样例扩展 → 期望 inline 错态「需要「读取日历」权限」+「去授权」→ 点去授权可恢复。

5. **卸载**  
   栖市 → 已安装 → 卸载样例扩展 → 桌面图标消失 → 再点原槽位无崩溃 → registry 无该 id。

6. **门禁关闭（默认）**  
   本地模式开 → 打开栖市无登录拦截 → 发现 Tab 不存在或隐藏。

7. **门禁开启（可选云）**  
   关本地模式 → 开云门禁 → 栖市尝试打开发现（若开 catalog）→ 期望「请先登录」→ mock 登录后可通过（占位即可）。

8. **成年审核**  
   开「启用成年确认门槛」→ 未验证时给样例 manifest 改 `contentRating: "mature"` 的 fixture（或第二测试包）→ 详情安装按钮禁用 + 文案 → 完成成年确认后可用。

9. **举报**  
   扩展 ⋯ → 举报 → 选「不当内容」提交 → 设置 → 举报队列出现一条 pending → 标记已读 → 状态更新。

10. **H6 默认关**  
    设置搜索无「本地聊天助手」→ 打开 `docs/LOCAL_CHAT_ASSISTANT.md` 存在且无外部品牌名 → 开启开关后出现说明页 + 桥接面板 → 粘贴文本 → 导入 Pop 草稿成功（不自动发送）。

**反向 / 坏数据：**

- 选非 zip 或缺 manifest 的 zip → 错态卡片，不白屏。
- manifest 含未知 `permissions` 项 → 安装拒绝，`bad_permissions`。
- 云 endpoint 为空但开关开 → 仅本地队列，控制台无未捕获异常。

### 9.3 自动

- [ ] `npm run verify:align-f7`

**脚本必须断言（非穷举 smoke）：**

1. `validateManifest()` 合法样例 → `{ ok: true }`；缺 `kind` / 非法 id / 未知 permission → 对应 `code`。
2. 权限表：`PERMISSION_IDS` 长度 ≥ 10 且含 `calendar.read`、`chat.send_token`；每项有 `labelZh`。
3. `checkPermission(granted, "calendar.read")` 允许 / 拒绝分支。
4. `permissionDeniedMessage("calendar.read")` 含「读取日历」。
5. `parseExtDesktopId("ext:foo")` → `{ extId: "foo" }`；非 ext 前缀 → null。
6. `normalizeGatePrefs({})` → `localMode === true`，`cloudGateEnabled === false`，`localChatAssistantEnabled === false`。
7. 样例 zip fixture 解包后 `entry` 文件存在。
8. `InstalledExtension` 安装 / 卸载 round-trip 纯函数（memory registry）不残留 icon 引用。

## 10. 开源注意

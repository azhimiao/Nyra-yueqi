## 4. 产品语义

1. 用户在 Pop 说话 → 时间线记一条「用户说：…」→ 下次组装 prompt 可见「同栖时间线」。  
2. 情景剧开幕 → 时间线记开幕 → 回 Pop 模型能读到。  
3. 日记场景 `appId=diary` → 抑制 `external` 段。  
4. 导出备份 JSON 含 `characters` / `scenario` / `cohabitTimeline` / `dataModules`。

## 5. 数据模型

### 场景标签
- 枚举：`pop|diary|scenario|sidewrite|shop|listen|read|calendar|system|cohabit`
- 策略：`SCENE_SECTION_POLICY`（diary/scenario 抑制 external 等）

### 同栖事件
```
{ id, at, appId, kind, summary, characterId, meta }
```
- Key：`yueqi.cohabit.timeline.v1`
- 上限 80；prompt 取 12

### 备份模块
见 `DATA_MODULES`：必含 `characters`、`scenario`、`cohabitTimeline`。

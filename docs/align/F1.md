## 1. 本波目标（用户可感知一句话）

**Pop 像真社交 App**：动态能发能互动、角色会自发更新；聊天里语音条可播、仿真通话有接通仪式；红包/转账/收款是信物卡片且钱包 ledger 对账；点赞评论与信物会涨羁绊值并在资料可见；夜间作息让回复更短更慢；离开一段时间后栖息唤醒轻轻跟一句——全部在栖机里闭环，不靠外部支付或真 RTC。

## 4. 产品语义（月栖用语，交互长什么样）

### 4.1 Pop 聊天（`data-phone-screen="pop"`）

**布局**：顶栏「Pop + 在线/睡着了/正在回复」；底栏四 Tab（聊天 / 通讯录 / 朋友圈 / 我）。聊天 Tab 默认会话列表（头像圆角 44px、未读点、最后一句预览）；点进线程后消息区 + 底 composer（贴纸钮 | 输入框 | 发送）。

**信物消息外观**：

- **红包**（`redpacket`）：左对齐卡片，宽约 72% 屏，渐变珊瑚底 `#e85d4c → #c94435`，圆角 12px；上行「信物 · 红包」小字；中行祝福语 2 行截断；下行「领取红包」按钮；已领半透明 +「已领取 · 8.88 栖币」。按下 180ms scale(0.98)。
- **转账**（`transfer`）：薄荷绿 `#4d9187` 横条卡，左 icon 转账，右金额 **`+/-` 栖币** 大字；附言灰色 12px。
- **收款**（`collect`）：浅灰底虚线边框，文案「向你收款」+ 金额 + 「确认支付」主按钮（disabled 余额不足）。
- **通话卡**（`call_voice` / `call_video`）：居中窄卡，图标 + 「语音通话 03:12」或「未接来电」红色标签；点按展开摘要折叠面板。

**语音条**：复用 `voice-message` 结构；Pop 内 `.mini-message` 嵌 `.voice-bar`，波形 3 条竖线动画播放态。

**贴纸**：贴纸消息无文字泡，仅 96×96 圆角 8px 图 + 可选 caption 10px。

**满屏特效**：聊天容器 `position:relative` 上叠 `data-fullscreen-effect` 层，`pointer-events:none`；红包打开时金币雨 1.2s；纪念日金色粒子。设置关闭后仅播卡片微动效。

### 4.2 动态（独立屏 `moments` + Pop 内联 Tab）

**顶栏**：返回 / 「朋友圈 · 你们的生活」/ 发布笔 icon。

**Feed 行**：左 36px 头像（角色卡 URL）；右栏作者名 11px 粗 + 时间 8px 灰；正文 12px 行高 1.55；配图区——单图高 168px 圆角 8px；多图 3 列网格 gap 4px（最多 9 张，末格 +N）。

**互动区**：右下点赞（心形 + 计数）、评论钮；点赞列表灰底条「❤ 你、林星梨」；评论灰底块逐条「**名**：文」；点评论展开 inline 输入 + 发送。

**空态**：`mini-empty` 换为插画占位（可用 CSS 渐变圆 + copy「还没有动态 · 发第一条吧」+ 按钮跳发布）。

**角色自发**：开关在 Pop「我」或设置「允许角色发朋友动态」；开启后每日最多 1 条 LLM 或模板 fallback，带来源 tag `authorType: character`。

### 4.3 Pop「我」与羁绊

**我 Tab**：头像 + 名；新增一行 **羁绊值** 进度条（0–100，-teal 填充）+ 文案「羁绊 · 68 · 亲近」；下挂钱包入口行「栖币钱包 · 余额 128.50」→ 进钱包屏（本波可 Pop 内 sheet 或独立 mini-view `wallet`）。

**钱包屏**：顶栏余额大字；下方 ledger 列表（时间 / 类型 icon / 金额红绿 / 摘要）；空 ledger 仅初始余额一行「系统赠送」。

### 4.4 仿真通话流程

1. 用户点 composer 扩展菜单「语音通话」→ 全屏 overlay 深色 blur；头像 + 「正在等待林星梨…」；Cancel 左下。
2. 1.5–3s 后「接通」→ 计时 MM:SS + 挂断红钮；无真实麦克风必选（可选文字快捷句注入 turn）。
3. 挂断 → 会话插入通话卡 + toast「通话已写入记忆」；`buildCallSessionMemory` 入库。

### 4.5 作息可感知（B11）

睡眠窗口内：Pop 顶栏「睡着了」；AI 回复延迟 +800ms 起且分段上限 2 句；若用户连发，先插入系统轻提示「她可能还没醒，但会尽量回你」仅一次/会话。

### 4.6 栖息唤醒（B13）

关栖机或 15min 无 `notifyUserActivity`：推送一条 proactive 短消息（≤40 字），Pop 会话列表该会话置顶 preview；同栖时间线事件 `kind: away_wake`。DND 时段静默。

## 5. 数据模型 / 协议（字段级）

### 5.1 聊天消息 `ChatMessageRecord`（扩展 `storage/db.js` metadata）

持久化于 IndexedDB `messages` store；metadata 为 JSON 对象。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✓ | `msg-{ts}-{rand}` |
| `sessionId` | string | ✓ | 现有会话 id |
| `role` | `"user"\|"assistant"\|"system"` | ✓ | |
| `content` | string | ✓ | 展示用主文案；信物可为祝福语 |
| `createdAt` | ISO string | ✓ | |
| `metadata.mediaType` | enum | 默认 `text` | 见下表 |
| `metadata.token` | object | 信物时 ✓ | 信物 payload，见 §5.2 |
| `metadata.voice` | object | voice 时 | `{ durationMs, transcript, audioDataUrl? }` |
| `metadata.sticker` | object | sticker 时 | `{ packId, stickerId, imageUrl, label }` |
| `metadata.call` | object | call_* 时 | `{ mode, status, durationSec, summary }` |
| `metadata.speakerName` | string | 群聊 | 已有 |
| `metadata.pending` / `failed` | boolean | 发送态 | Pop 已有 |

**`metadata.mediaType` 枚举**

| 值 | 含义 | 降级 |
|----|------|------|
| `text` | 普通文本 | — |
| `voice` | 语音条 | 无 audio 仍显示条，播放 disabled |
| `sticker` | 贴纸 | 缺图 → 显示 label 文本 |
| `redpacket` | 红包 | 非法 → `text` |
| `transfer` | 转账 | 非法 → `text` |
| `collect` | 收款 | 非法 → `text` |
| `call_voice` | 语音通话卡 | — |
| `call_video` | 视频通话卡 | — |
| `system` | 系统提示 | 不参与羁绊 |

### 5.2 信物 payload `TokenPayload`（`metadata.token`）

| 字段 | 类型 | 规则 |
|------|------|------|
| `kind` | `"redpacket"\|"transfer"\|"collect"` | 与 mediaType 一致 |
| `amount` | number | >0，≤99999，最多 2 位小数 |
| `currency` | string | 固定展示「栖币」，存储 `"nyra_coin"` |
| `note` | string | ≤ 60 字 |
| `status` | enum | `pending` / `opened` / `completed` / `expired` |
| `direction` | `"in"\|"out"` | 相对当前用户 |
| `counterpartyId` | string | 角色 id |
| `ledgerId` | string | 钱包入账后回填 |

**inline 解析语法**（LLM 或用户粘贴，由 `src/tokens/parse.js` 统一处理）：

```
[信物:redpacket amount=8.88 note=节日快乐]
[信物:transfer amount=50 note=午饭 direction=out]
[信物:collect amount=12 direction=in]
```

解析失败返回 `{ ok:false, fallbackText: original }`，UI 渲染普通文本气泡。

**校验降级对象**（`src/tokens/validate.js`）：

```js
{ ok: false, errors: ["amount_invalid"], display: { mediaType: "text", content: "〔信物格式有误，已当普通消息显示〕" } }
```

### 5.3 钱包 `WalletState` + ledger（I3）

**存储键**：`yueqi.wallet.v1`（localStorage；备份模块 id `wallet`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `balance` | number | 当前余额，≥0 |
| `currency` | `"nyra_coin"` | |
| `updatedAt` | ISO string | |
| `ledger` | `LedgerEntry[]` | 最多保留 500 条，超出删最旧 |

**`LedgerEntry`**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | `ldg-{ts}` |
| `type` | `"credit"\|"debit"` | |
| `amount` | number | 正数 |
| `balanceAfter` | number | 事务后余额 |
| `reason` | string | `token.redpacket` / `token.transfer` / `token.collect` / `system.grant` / 预留 `shop.purchase` |
| `refMessageId` | string? | 关联聊天消息 |
| `refCharacterId` | string? | |
| `note` | string | ≤80 |

**API（`src/wallet/ledger.js`）**

- 初始安装：`balance: 200`，ledger 一条 `system.grant`

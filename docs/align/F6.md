## 4. 产品语义（月栖用语，交互长什么样）

### 4.1 接口页 · 生图 + 语音（配置入口）

> 现有 `[data-phone-screen="lab"]` 在 `app-screens.js`；语音表单已部分存在，**本波补全**。

1. 用户从栖机 Home 点 **接口**（`lab`，`plug-zap`，tone `ink`）。
2. 滚动区三段，视觉上用 `mini-form__title` 分隔（U3）：
   - **模型**（已有，不动）
   - **语音**（已有 TTS 段；**追加** STT Key / Model 字段 +「测试朗读」「测试转写」小按钮，行为对齐 App 版 `panels/profile.js`）
   - **生图**（**新增**）：Provider 分段（默认 OpenAI 兼容 `images/generations`）、Base URL（可空=跟随模型 Base URL）、API Key（password）、Model（placeholder `dall-e-3`）、默认尺寸（`1024x1024` / `512x512`）；保存按钮「保存生图」
3. **无 Key 时**：保存仍可用（清空 Key）；各 App 读配置后走降级，**不在此页阻塞导航**。

### 4.2 G1 · 绘境 App（生图主路径）

| 项目 | 值 |
|------|-----|
| App id | `studio` |
| 标签 | **绘境** |
| 图标建议 | `wand-sparkles`，tone `coral`，`page: 2` |

**流程：**

1. **桌面** → 点 **绘境** → 300ms 内出壳：顶栏「绘境 / 描述你想画的画面」+ 返回 Home。
2. **输入区**（屏中下）：多行 textarea（max 800），placeholder「例如：窗边的星梨，傍晚，柔光」；下方主按钮 **生成**（U6：idle / loading / disabled）。
3. **有 Key**：点生成 → 按钮 loading + 进度文案「正在绘制…」→ **结果页**（同 App 内层，非 alert）：
   - 大图区（object-fit contain，品牌色细边框）
   - 副栏：prompt 摘要、生成时间
   - 操作：**存入相册**（主）、**再画一张**（次）、**复制描述**（可选）
4. **存入相册**：自动确保存在分组 **「AI 创作」**（`groupId` 稳定 `pg-ai-studio`）；调用统一媒体层 → `media` store + `library.photos` → toast「已存入相册」+ 次级链「去相册查看」可点。
5. **无 Key**：进入绘境见空态插画 +「还没有配置生图接口」+ 主按钮 **去接口页**（`openApp("lab")` 并 scroll 到生图段）；桌面图标可选 **半透 + 角标** 或正常可进空态（二选一，**必须有说明**）。
6. **失败**：结果区错态卡片「生成失败：{简短原因}」+ **重试**；控制台无 uncaught。

**历史（最小）：** 结果页底「最近生成」横向缩略条（最多 6 条，本地 job 记录）；点缩略图可回看，不要求云端同步。

### 4.3 G2 · TTS（Pop + 接口）

**Pop 线程页**（`data-pop-chat-mode="thread"`）：

1. 助手气泡右下角 **朗读** 图标钮（`volume-2`），仅当 `canSpeak()` 为真 **或** disabled 且 `title="请先在接口页配置语音"`（U7）。
2. 点击 → 钮进入 `is-speaking`（已有 `tts.js` 样式）→ 播放结束恢复；播放中再点 = 停止。
3. 新回复到达：若 `shouldAutoSpeak()` → 调 `speakSegmentedText`（与 `panels/chat.js` 一致）；失败 **静默 catch**，不弹栈。
4. **接口页**：「测试朗读」用固定样句「你好，我是月栖。」→ 成功播放 / 失败 inline 红字。

**App 版聊天**（`panels/chat.js`）：已有实现；本波仅 **回归验证、不重写**，改 public API 须向后兼容（E8）。

### 4.4 G3 · STT（Pop composer）

1. Pop composer 在 `[data-phone-sticker]` 与发送钮之间插入 **麦克风**（`mic`），44×44 热区（U8）。
2. **按住**（pointerdown）→ 检查麦克风权限（`src/platform/permissions.js` `ensureMicrophonePermission`）→ `startRecording()` → 钮 `is-recording` 脉冲。
3. **松开**（pointerup / pointerleave）→ `stopRecording()` → `transcribeAudio` → 文本 **写入** `[data-phone-chat-input]`，**不自动发送**（用户可编辑后再发；与 App 版一致）。
4. 转写中：输入框 placeholder「识别中…」；失败：composer 上方 inline「未识别到文字」+ 重试。
5. **无 STT Key**：复用 `isSttConfigured()`；麦克风 hidden 或 disabled + 说明。

### 4.5 G5 · 场景工坊 App

| 项目 | 值 |
|------|-----|
| App id | `workshop` |
| 标签 | **场景工坊** |
| 图标建议 | `box`，tone `mint`，`page: 2` |

**布局（像 App，不像调试页）：**

```
┌─────────────────────────────┐
│ ‹  场景工坊    星梨的傍晚  │  mini-appbar
├─────────────────────────────┤
│                             │
│     [ 3D 视口 / 降级海报 ]   │  flex 1，圆角 12px，浅阴影
│                             │
├─────────────────────────────┤
│  重置视角  │  关于此场景   │  工具栏 48px，两钮居中
└─────────────────────────────┘
```

1. 进入 → **立即**渲染 appbar + 视口占位（渐变 + 骨架 shimmer，E9）→ 异步加载内置场景 `assets/scenes/default-room.glb`（或等价 JSON + 贴图 bundle）。
2. **成功**：Three.js（或等价）渲染单场景；OrbitControls 限位；工具栏显示场景名 **「默认小室」**；重置视角恢复初始 camera。
3. **失败降级**（E6）：视口换 **2D 海报**（`/assets/scenes/default-room-poster.webp`）+ 文案「3D 场景暂时无法加载」+ **重试** + 说明「不影响其它 App」。
4. **无 API Key 依赖**：场景工坊 **不依赖** 生图/语音 Key；验收必须能在零 Key 环境打开。
5. **关于此场景**：底部 sheet 只读 — 场景 id、来源「内置」、一句氛围描述。

**动效：** 视口 fade-in 200ms；`prefers-reduced-motion` → instant（U5）。

### 5.2 ImagegenSettings（`yueqi.imagegen.v1`）

```typescript
/** @typedef {object} ImagegenSettings */
{
  schemaVersion: 1,
  provider: "openai-compatible",   // 本波仅此一种；预留 provider 字段
  apiKey: string,                  // 明文 localStorage；备份导出时剥离
  baseUrl: string,                 // 空串 = 读 yueqi.provider.v1.baseUrl 或默认 OpenAI v1
  model: string,                   // 默认 "dall-e-3"
  defaultSize: "1024x1024" | "512x512" | "1792x1024" | "1024x1792",
  enabled: true,                   // 用户可关生图而不删 Key
}
```

**默认：** `{ schemaVersion: 1, provider: "openai-compatible", apiKey: "", baseUrl: "", model: "dall-e-3", defaultSize: "1024x1024", enabled: true }`

**纯函数：**

- `getImagegenSettings()` / `saveImagegenSettings(partial)`
- `isImagegenConfigured(settings?)` → `Boolean(enabled && apiKey.trim())`
- `exportImagegenSettingsForBackup()` → 剥离 `apiKey`

### 5.3 ImagegenJob（jobs 数组元素）

```typescript
/** @typedef {object} ImagegenJob */
{
  schemaVersion: 1,
  id: string,                      // `igj-{timestamp}-{rand}`
  status: "queued" | "running" | "succeeded" | "failed",
  prompt: string,                  // 用户原文，≤800
  revisedPrompt: string | null,    // 上游返回则存
  createdAt: string,               // ISO8601
  finishedAt: string | null,
  error: string | null,            // 失败摘要 ≤200 字
  mediaId: string | null,          // 成功后关联 media store
  photoId: string | null,          // 存入相册后的 library photo id
  width: number,
  height: number,
  model: string,
}
```

**校验 / 降级（E3）：**

- `validateImagegenJob(raw)` → `{ ok, value?, errors[] }`
- `degradeImagegenJob(raw)` → 最小可渲染 job（`status:"failed"`, `prompt:""`, `schemaVersion:1`），**不 throw**

### 9.1 本波功能手测（路径级，必须逐步照做）

#### 前置

1. `npm install`；`npm run start` 或 dev + server；浏览器打开栖机（375×812）。
2. 准备：**环境 A** 无任何 Key；**环境 B** 在接口页配置有效生图 Key + TTS/STT Key（可用 OpenAI 兼容）。

#### 环境 A · 无 Key 降级

1. **绘境**  
   - 期望：可进 App 或图标 disabled，但 **有说明**；点「生成」若可见则 **不白屏**，引导去接口；控制台无 uncaught。

2. **Pop 语音**  
   - 期望：朗读钮 / 麦克风 **hidden 或 disabled**；hover/focus 有「去接口配置」类说明。

3. **场景工坊**  
   - 期望：**零 Key 可进**；见 3D 或 poster 降级，**不是**空白 div。

#### 环境 B · G1 生图 → 相册

4. **接口 → 生图** 填 Key / Model → 保存。  
5. **绘境** 输入 prompt → 生成 → 见 loading → 结果图。  
6. 点 **存入相册** → toast 成功 → **相册 → AI 创作** → 缩略图可见 → lightbox 打开 **同一张图**。  
7. 杀页重进 → 相册仍在（IndexedDB + library）。

#### 环境 B · G2 TTS

8. **Pop** 打开会话 → 助手一条文字回复 → 点 **朗读** → 听到音频 → 再点停止。  
9. 接口页开 **自动朗读** → 新回复到达 → 自动播一段（可分段）。  
10. 故意错 Key → 朗读失败 **alert 或 inline**，页面仍可输入。

#### 环境 B · G3 STT

11. Pop composer **按住说话** → 说「你好月栖」→ 松开 → 输入框出现转写文字 → 手动发送 → 正常收到回复。  
12. 拒权麦克风 → 有说明，不 crash。

#### G5 场景工坊

13. 打开 **场景工坊** → 300ms 内见 appbar + 视口。  
14. 成功路径：可拖动视角（或静态海报上有 parallax 也算 MVP 需文档注明）；**重置视角**有效。  
15. **失败路径**：DevTools 阻断 glb 或 mock loader 抛错 → poster 降级 + 重试，**不白屏**。

#### 反向 / 离线

16. 断网点击生成 → 错态 + 重试，已存相册图片仍可看。  
17. `localStorage` 清空 voice Key 后 **无需刷新** 或 刷新后 Pop 钮状态正确（disabled）。

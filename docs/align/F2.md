## 4. 产品语义（月栖用语，交互长什么样）

### 4.1 外层：侧写 App（C0 选角台）

1. 用户在栖机 Home 点 **侧写**（图标建议 `eye` 或 `smartphone`，tone `ink`，`page: 2`）。
2. 全屏 `mini-view`，顶栏：左返回栖机 Home，标题 **侧写**，副标题「选一位角色」。
3. 主体为 **选角台列表**：每行 56px 高——左圆角头像（`character.avatarUrl` 或首字渐变底），中列主名 + 副文案（alias 或「TA 的屏幕」），右 chevron；列表可滚动，≥1 角色。
4. 点一行 → 300ms 内切到 **TA 的屏幕**（见 4.2）；返回键回到选角台（保留滚动位置）。
5. **空角色**（仅内置且未扩展）：仍显示内置角色，不得空白页。

### 4.2 内层：TA 的屏幕（独立桌面层级 — 验收硬门槛）

> 以下层级 **与外栖机壳并行**，CSS 命名空间建议 `ta-*`，挂载在 `[data-phone-screen="sidewrite"]` 内的 `[data-ta-screen="desktop"]`。

| 分区 | 描述 |
|------|------|
| **TA 状态栏** | 高 28–32px，半透明；左：虚构运营商名（如「栖网」）；中：可选留空；右：信号条 + 电池 icon + **实时时钟**（与外栖机可同源 `formatClock`） |
| **壁纸区** | 占屏高约 45%；角色向渐变色或从 `manifest.desktop.wallpaperId` 读取预设；允许轻 blur 衬底 |
| **图标网格** | 壁纸下 **4 列**图标：MVP 固定顺序 **讯息(C5)、相册(C4)、备忘(C8)、短信(C2)**；图标下 2 行以内中文标签；长按 **不**进入编辑模式（F2a） |
| **Dock** | 底栏四格，毛玻璃；可复用四 App 快捷方式或留两格空位；点击与外网格一致 |
| **顶栏返回** | 左「‹ 选角」回选角台；标题显示 **角色名 + 的屏幕**（如「林星梨的屏幕」），不用 internal id |

**导航栈：** `desktop → subAppList → subAppDetail`；子 App 内顶栏左返回上一栈层；**TA Home**（底部小横条或手势）仅回 TA 桌面，不退出侧写。

**动效：** 进入子 App  slide-in 200ms；`prefers-reduced-motion` 时 instant（U5）。

### 4.3 子 App：C5 讯息（即时通讯）

- **列表页：** 顶栏「讯息」+ 搜索占位（F2a 可 disabled）；行：圆头像（颜色/emoji）、标题（备注名）、预览一行 ellipsis、右对齐时间、未读红点。
- **对话页：** 顶栏显示会话名；内容区按日 `—— 3月12日 周二 ——` 分隔；**对方左灰/白气泡、角色自己右品牌色气泡**（U10）；底部 **只读**，无输入框（这是偷看，不是替角色发消息）。
- **空态：** 插画区 +「还没有聊天记录」+ 主按钮「生成痕迹」（触发 C17）。
- **生成中：** 列表骨架 3 行 + 顶部细进度；失败：toast +「重试」。

### 4.4 子 App：C4 相册

- **相册页：** 2 列封面卡片，封面为 **渐变 tile + 张数角标**；标题如「日常」「旅行」。
- **网格页：** 3 列方格缩略图；点进 **灯箱预览**：大图区同色渐变、下附 `caption` 与 `takenAt`。
- **空态：** 「相册是空的」+ 生成按钮。

### 4.5 子 App：C8 备忘

- **列表：** 卡片：标题 bold、摘要 2 行、右下日期；置顶项带 📌 或浅色顶条。
- **详情：** 大标题 + 正文 `white-space: pre-wrap`；无编辑控件。

### 4.6 子 App：C2 短信

- **列表：** 与 C5 类似但更「系统短信」风——左 monogram 圆、号码掩码、预览。
- **对话：** 收发气泡 **左右分列**（发出绿色系、接收灰白）；无输入框。

### 4.7 生成流（C17，跨 App）

1. 首次进入某子 App 且无 payload → 立即渲染 **空壳 UI**（E9）。
2. 若 provider 已配置 → 后台调 LLM，system 提示「为角色 X 生成侧写 JSON，仅输出 JSON」。
3. 校验通过 → 写入 store → 刷新 UI → manifest `generationStatus: "ready"`。
4. 部分 App 失败 → `partial` + 失败 App 可单独重试。
5. 无 provider → 保持空态，手测仍可过路径（不抛 uncaught）。

### 4.8 投影与回 Pop（C18 / P1）

- 用户 **打开** C5 列表 → 事件 `action: "open_app"`。
- **进入**某会话/thread → `view_thread` + `excerpt` 为最后一条对方消息前 80 字（脱敏）。
- 停留详情 **≥3s** → 追加 `dwell`（可合并同 target 30s 内去重）。
- 回 Pop 问「你知道我刚看了什么吗」→ 模型应能引用 **同栖时间线** 中 `summary`（有 key 时语义回复；无 key 时 dev 面板可见事件即 PASS）。

### 4.9 F2b / F2c（摘要）

- **F2b：** 每 App 复用 F2a 的「列表 → 详情 → 返回」与 schema/生成/投影模式；C6 订单详情展示商品名、金额、`orderId`。
- **F2c：** 桌面图标数约 8；池内 App 未启用时不占位；启用后图标与 F2a 共用 Dock/网格样式。

### 5.2 SidewriteManifest（每角色一条，键 `{characterId}:manifest`）

```typescript
/** @typedef {object} SidewriteManifest */
{
  schemaVersion: 1,                    // 固定 1
  characterId: string,                 // 角色 id，与 store.js 一致
  createdAt: string,                   // ISO8601
  updatedAt: string,                   // ISO8601
  generationStatus: "idle" | "generating" | "ready" | "partial" | "failed",
  generationError: string | null,      // 最后一次全局失败摘要，≤200 字
  desktop: {
    wallpaperId: string,               // 预设 id，如 "dusk" | "mint" | "char-{characterId}"
    wallpaperTone: string,             // 对齐 phone-shell tone：mint|coral|ink|yellow|blue|white
    iconOrder: string[],               // F2a: ["c5","c4","c8","c2"]；F2c 扩展至 ~8
    dockOrder: string[],               // 长度 4；null 表示空槽，如 ["c5","c4",null,null]
    carrierLabel: string,              // 状态栏运营商，默认 "栖网"
  },
  apps: {
    [appKey: string]: {
      status: "empty" | "generating" | "ready" | "failed",
      generatedAt: string | null,
      checksum: string | null,         // payload 稳定 hash，可选
      error: string | null,
    },
  },
  pool: {                              // F2c 才写入
    seed: number,                      // 整数，默认来自 characterId hash
    enabledApps: string[],             // 池子 id 列表
  },
}
```

**默认 manifest（新角色）：** `generationStatus: "idle"`，四 App `status: "empty"`，`desktop.iconOrder` 为 F2a 四键。

### 5.3 C5 讯息 payload（`appKey: "c5"`）

```typescript
/** @typedef {object} SidewriteImPayload */
{
  schemaVersion: 1,
  appKey: "c5",
  threads: Array<{
    id: string,                        // 稳定 slug，如 "thread-mom"
    title: string,                     // 会话显示名，≤24 字
    avatarHint: string,                // emoji 或 1 字，如 "妈"
    lastMessagePreview: string,        // ≤60 字
    lastMessageAt: string,             // ISO8601
    unreadCount: number,               // 0–99
    pinned: boolean,
  }>,
  messagesByThread: {
    [threadId: string]: Array<{
      id: string,
      role: "self" | "other" | "system",  // self = 该角色自己
      senderName: string | null,       // group 时显示
      content: string,                 // ≤500 字；禁止 HTML
      sentAt: string,                  // ISO8601
      type: "text" | "image" | "voice" | "sticker",
      meta: { label?: string } | null, // 非 text 时的占位说明
    }>,
  },
}
```

**校验规则：** `threads.length` 0–20；每个 thread 至少 0 条 messages；messages 按 `sentAt` 升序；`role` 必填。失败 → **降级** `{ schemaVersion:1, appKey:"c5", threads:[], messagesByThread:{} }`。

### 5.7 投影事件（C18 → 同栖时间线）

写入 F0 **LivingTimelineEvent**（F2 定义、F0 收录；字段不得删减）：

```typescript
/** @typedef {object} SidewriteProjectionEvent */
{
  id: string,                          // `sw-${Date.now()}-${random}`
  ts: string,                          // ISO8601
  characterId: string,
  sourceApp: "sidewrite",              // 固定
  appId: "sidewrite",                  // I5 场景标签用
  sceneTag: "sidewrite.view" | "sidewrite.im" | "sidewrite.album" | "sidewrite.memo" | "sidewrite.sms",
  action: "open_app" | "view_thread" | "view_album" | "view_note" | "view_sms" | "dwell",
  summary: string,                     // 给 prompt 读的中文一句，≤120 字，如「用户查看了林星梨短信中与妈妈的对话」
  payload: {
    subApp: "c2" | "c4" | "c5" | "c8" | /* F2b/c 扩展 */,
    targetId: string | null,
    targetTitle: string | null,
    excerpt: string | null,            // ≤80 字，禁止密钥/邮箱全文
    dwellMs: number | null,
  },
  ttlHours: 48,
}
```

**sceneTag 映射：** c5→`sidewrite.im`；c4→`sidewrite.album`；c8→`sidewrite.memo`；c2→`sidewrite.sms`；仅打开 TA 桌面→`sidewrite.view`。

**assemble.js 衔接（修改点）：** 在 `assemblePrompt` 返回的 compiled 对象增加 `livingTimelineBlock: string`；由 `src/sidewrite/projection-format.js` 的 `formatSidewriteTimelineBlock(characterId)` 读取近 48h、`sourceApp==="sidewrite"` 事件，格式化为：

```text
同栖时间线（侧写）：
1. [sidewrite.im / 12:04] 用户查看了讯息「妈妈」中最后一条：「记得吃饭」
```

注入 `buildSystemContent` 时置于 **memory 块之后、daily 之前**；仅当存在事件时注入（E4：无事件不注入，避免空污染）。

### 5.8 LLM 生成请求 / 响应（C17）

- **请求：** 单 App 单次生成；user 块含 `character.name`、`character.alias`、profile 摘要（`collectCharacterProfile` 精简版）、目标 `appKey`、JSON Schema 文字描述。
- **响应：** 裸 JSON 或 \`\`\`json 包裹；解析后走 `validateSidewritePayload(appKey, raw)`。
- **降级：** 校验失败 3 次 → manifest.apps[appKey].status=`failed`；UI 保持空态 + 错误文案，**不** `throw` 到页面级。

### 5.9 F2b / F2c payload 占位

F2b/c 详细 schema 在对应切片补充；F2a 的 `validate.js` 对未知 `appKey` 返回 `{ ok:false, reason:"unknown_app" }`。C6 订单 **预留**字段：`orderId: string`, `amount: number`, `currency: "CNY"`, `shopName: string`, `status: "pending"|"paid"|"shipped"|"done"`.

### 9.1 本波功能手测（路径级，必须逐步照做）

#### 前置

1. 本地已 npm 安装依赖；浏览器打开栖机；至少 1 个角色（内置林星梨即可）。
2. （可选）在「接口」页配置 LLM；未配置则走空态/ fixture 路径。

#### F2a 主路径

1. **栖机 Home → 侧写**  
   - 期望：进入选角台；列表项含 **头像 + 角色名**（非 `char-xingli` 裸 id）；顶栏标题「侧写」。

2. **选角 → TA 的屏幕**  
   - 期望：300ms 内出现 **TA 状态栏 + 壁纸 + 4 图标 + Dock**；标题含「林星梨的屏幕」（或当前角色名）；左「选角」可回列表且 **列表滚动位置保留**。

3. **讯息 C5：列表 → 对话**  
   - 点「讯息」→ 会话列表（≥0 行）；点一行进对话 → **左右气泡 + 日期分隔**；返回列表滚动不丢；无数据时空态 +「生成痕迹」。

4. **相册 C4**  
   - 相册封面网格 → 点相册 → 照片 grid → 点照片全屏预览（caption 可见）；空相册空态。

5. **备忘 C8**  
   - 列表 → 点笔记 → 详情只读 → 返回。

6. **短信 C2**  
   - 列表含掩码号码 → 对话页 in/out 气泡分列 → 返回。

7. **生成流（有 provider 时）**  
   - 清该角色 c5 payload → 进讯息 → 立即见壳 → 生成中反馈 → 成功后刷新仍在 → 杀页重进数据仍在 IndexedDB。

8. **生成失败**  
   - 模拟坏 JSON（fixture 或 mock）→ 页面不白屏；显示错态 + 重试；控制台无 uncaught。

9. **投影 / 回 Pop（P1）**  
   - 在 C5 打开某 thread 停留 ≥3s → 回 Pop → 发「你知道我刚看了什么吗」  
   - 期望：回复能提及所看会话/摘要 **或**（无 LLM key 时）在 prompt debug/时间线可见 `sourceApp: sidewrite` 事件且 `summary` 非空。

10. **角色不串（P2）**  
    - 若有第二角色：侧写选 B → 讯息/相册应显示 B 的数据或空态，**不得**出现 A 的头像/名字。

#### F2b（该切片交付时追加）

11. 打开购物订单 C6 → 订单详情含 `orderId` 字段；与 F3 栖店下单 id **格式一致**（人工对照字段即可）。  
12. 浏览器/邮箱/电话记录：各 **列表 → 详情 → 返回** 一遍。

#### F2c（该切片交付时追加）

13. 同一角色桌面显示 **约 8 个**池 App 图标；刷新后顺序不变。  
14. 换角色图标集合随 seed 变化。

#### 反向 / 失败

- 无 provider：四 App 空态可进可退，不抛异常（E6）。  
- 断网：已缓存 payload 仍可浏览；生成按钮错态可重试。  
- 外栖机 Home 键：从 TA 子 App **应先回 TA 桌面**；从 TA 桌面再退才回选角/外 Home（栈序正确）。

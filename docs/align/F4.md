## 4. 产品语义（月栖用语，交互长什么样）

### 4.0 剧章 vs 情景剧（Agent 必须先读懂）

| 维度 | **剧章 E1** | **情景剧 E5** |
|------|-------------|---------------|
| 入口 | 栖机新图标「剧章」`story` | 已有「情景剧」`scenario` |
| 核心动作 | 读文本 + **点选项**跳转节点 | **共演**：选项或自由说 → 导演推进 |
| 内容来源 | 预置/导入 **节点图 JSON** | 剧本库 + 运行时 **beats** |
| 视觉 | 书页/章节封面 + 选项 pill 条；像「互动阅读」 | 全出血舞台、帷幕、张力氛围 |
| 记忆 | 章末可选写入同栖时间线（读完某章） | 谢幕摘要 → 日记/记忆 |
| 代码 | 新建 `src/story/` | **扩展** `src/scenario/*` |

二者**不得共用同一套 UI 壳**；剧章禁止套用 `scenario-theater.css` 的舞台层。

### 4.1 E1 · 剧章

**路径：** 栖机桌面「剧章」→ **目录**（封面缩略 + 进度点）→ 点一章 → **章节封面**（标题、一句 hook、主色条）→「开始阅读」→ **阅读屏**（上方进度「第 n 幕」，中部正文区 serif 排版，底部 **2–4 个选项 pill**）→ 选支后正文切换（150–220ms 淡入）→ **结局页**（标题「本章收束」+ 摘要 + 「重读本章 / 回目录」）。

- **目录屏**：375 宽下每行 = 封面色块（章主题色）+ 章名 + 副标题；已通关角标「已读完」；进行中显示「续读」
- **空态**：仅内置一章时也须像 finished App，不是 debug 列表
- **错态**：损坏存档 → 「这一章走散了」+ 重置进度按钮

### 4.2 E5 · 情景剧加深（对接现有）

**已有：** `mountScenarioTheater` 在 `phone-shell.js` → 门厅 / 开幕 / 台上 / 谢幕；`store.js` 键 `yueqi.scenario.v1`；`director.js` JSON 契约；5 个预设剧本。

**本波加深：**

1. **门厅**：增加「自写剧本」入口 → 表单（标题 / premise / openingBeat / mood）→ 保存进 `bag.scripts`
2. **开幕**：可选关联 `loreEntryIds`（读 `characters` 与世界书已有 id 列表，无 F5 完整 UI 也可多选 chips）
3. **台上**：`data-tension="0|1|2|3"` 驱动 `scenario-theater.css` 色温/颗粒微动（尊重 `prefers-reduced-motion`）
4. **谢幕**：摘要 textarea 旁增加「写进日记」→ 调现有 diary API / 写 memory；可选投影同栖时间线 → `appendCohabitEvent({ appId: "scenario", ... })`（形状见 §5.5）
5. **暂离 / 续演**：保持现有；刷新后 beats 仍在

**约束：** 不删 S0/S1 已交付路径；加深只做 additive；Stage 仍「演」优先，不在台上塞设定大表单。

### 4.3 E6 · 共创

**路径：** 栖机「共创」→ **类型选择**（「补人设」|「写一幕剧本」）→ 表单（角色下拉 / 关键词 / 语气）→ 「生成草稿」（有 key 调模型；无 key 走 **离线模板** 填充，见 §5.4）→ **预览对比**（左旧 / 右新 或 上下分屏）→ 「写入角色卡」或「存入剧本库」。

- 写入角色：映射到 `profile.fields[4]`（人设摘要）或 `profile.tokens`；须调 `upsertCharacter`
- 写入剧本：调 `scenario/store` 新增 user script（`source: "cocreate"`）
- 成功 toast + 跳转链接（「去角色页查看」/「去情景剧开演」）

### 4.4 E7 · 游戏大厅

**路径：** 栖机「游戏」→ **大厅**（两张大卡片：游戏名 + 最高分 + 「开始」）→ 全屏 **小游戏页**（顶栏返回 + 标题；中部游戏区；底部分数条）→ 结束 **结算条**（本局分 / 最高 / 再玩一局）。

| 游戏 id | 名称建议 | 玩法摘要 |
|---------|----------|----------|
| `match-pairs` | 星灯配对 | 4×4 翻牌，步数+用时计分 |
| `tap-rhythm` | 落点反应 | 30s 内点击出现圆点，连击加分 |

禁止浏览器原生 dialog 当主界面；分数写入本地 store。

### 4.5 E8 · 联机

**默认路径 B（deferred）— 本波必交付；路径 A（local）为可选加分。**

**设置 → 玩法 → 联机房间**（新小节）：

- 开关 `multiplayer.enabled`，**默认 `false`**；`mode` 默认 **`deferred`**
- **B · deferred（必做）**：关 → 游戏大厅或独立「联机」入口显示 **本地暂缓** 说明（「当前版本仅单机；打开联机实验需…」）+ 「敬请期待」态；不可 silently 联网
- **A · local（可选）**：开开关且 `mode: "local"` → 大厅 → 创建房间（6 位码）→ 等待页 → 两人各玩一局同款小游戏 → 分数同步展示（最小即可）

### 5.2 E1 · 剧章图 `StoryChapter`

```ts
{
  id: string                    // e.g. "ch1-rain-letter"
  title: string
  hook: string                    // 封面一句
  theme: "mint" | "coral" | "ink" | "yellow"  // 对齐 phone-shell tone
  startNodeId: string
  nodes: StoryNode[]
  version: 1
}
```

### 5.3 E1 · 节点 `StoryNode`

```ts
{
  id: string
  kind: "beat" | "choice" | "ending"
  body?: string                   // beat/ending 正文（支持 \n\n 分段）
  choices?: { id: string; label: string; nextNodeId: string }[]  // choice 节点 2–4 项
  endingTitle?: string            // ending 专用
  endingSummary?: string
}
```

**引擎纯函数（须单测）：**

- `validateChapter(chapter): { ok: boolean; errors: string[] }`
- `reachability(chapter): Set<nodeId>` — 从 `startNodeId` BFS，**必须等于** `nodes` 中可达节点
- `advanceNode(chapter, nodeId, choiceId?): { nextNodeId | null; error? }`
- `normalizeProgress(raw): StoryProgress` — 坏数据降级为 `{ chapterId: "", nodeId: "", completed: [] }`

### 5.4 E1 · 进度 `StoryProgress`（存 `yueqi.story.v1`）

```ts
{
  activeChapterId: string
  activeNodeId: string
  completedChapterIds: string[]
  updatedAt: string               // ISO
}
```

内置第一章建议 id `ch1-missing-page`：≥5 个节点、≥2 次 choice、≥1 ending（验收用）。

### 5.5 E5 · 情景剧（扩展，兼容现有）

**`ScenarioScript`**（`store.js` / `presets.js` 已有字段，本波补齐用法）：

- 用户自写：`source: "user" | "cocreate"`，写入 `bag.scripts[]`
- 可选 `loreEntryIds: string[]`

**`ScenarioRun.directorState`**（已有）：本波 UI 必须展示张力 0–3；`parseDirectorOutput` 已处理 `tensionDelta`。

**谢幕写回 · 同栖时间线（F0 I2 canonical，对齐 `src/memory/cohabit-timeline.js`）：**

勿使用 F2 §5.7 侧写草案 `LivingTimelineEvent`（`ts` / `sourceApp` / `sceneTag` / `action` / `payload` / `ttlHours`）。本波情景剧与 Pop 开幕写入**同一** `CohabitTimelineEvent` 形状：

```ts
/** appendCohabitEvent(input) 落库字段（id/at 由 API 生成） */
{
  id: string
  at: string                      // ISO8601
  appId: "scenario"               // I5 场景标签；固定 "scenario"（勿写 sourceApp）
  kind: "open" | "finale" | string // 开幕已有 kind: "open"；谢幕建议 "finale"
  summary: string                 // ≤240 字，prompt 可读一句
  characterId: string             // 卡司 leadId 或 ""
  meta?: {
    scriptId?: string
    runId?: string
    finaleSummary?: string
  }
}
```

**调用示例（谢幕）：**

```ts
appendCohabitEvent({
  appId: "scenario",
  kind: "finale",
  summary: `谢幕《${title}》：${finaleSummary.slice(0, 80)}`,
  characterId: run.cast?.leadId || "",
  meta: { scriptId: run.scriptId, runId: run.id, finaleSummary },
});
```

### 5.6 E6 · 共创草稿 `CocreateDraft`

```ts
{
  id: string
  target: "character" | "script"
  characterId?: string
  input: { prompt: string; tone?: string; keywords?: string[] }
  output: {
    characterPatch?: { fieldIndex?: number; text?: string; tokens?: string[] }
    scriptPatch?: { title: string; premise: string; openingBeat: string; mood: string }
  }
  createdAt: string
  appliedAt?: string
}
```

**LLM 输出 schema**（`appId: "cocreate"`）：`{ "characterSummary"?: string, "tokens"?: string[], "script"?: { title, premise, openingBeat, mood } }` — 解析失败 → 离线模板，不白屏。

### 5.7 E7 · 游戏分 `GamesBag`

```ts
{
  scores: Record<string, { high: number; last: number; plays: number; updatedAt: string }>
}
```

键名：`match-pairs` · `tap-rhythm`。

### 5.8 E8 · 联机 prefs

```ts
{
  enabled: boolean               // default false（B 路径不要求开）
  mode: "deferred" | "local"     // default "deferred"（B）；local = 可选 A
  lastRoomCode?: string          // 仅 mode === "local" 时使用
}
```

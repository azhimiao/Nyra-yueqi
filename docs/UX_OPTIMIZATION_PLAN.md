# 月栖 · 体验优化迭代计划

> 目标：优先修「用户感受」——尤其是「我的」页美观，以及聊天 / 设定的输入流畅度。  
> 原则：先主路径，再设置；每期可验收；这几期不堆新旁路功能。  
> 关联：[PRODUCT_ROADMAP.md](./PRODUCT_ROADMAP.md) · [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)

**状态**：第 1 期进行中 / 已落地微信式「我的」  
**最近更新**：2026-07-24

---

## 0. 问题诊断

### 0.1 「我的」页

- 设定与「我的」合并后，呈现为「左侧长目录 + 右侧旧设定块」，像后台 CMS，不像陪伴产品。
- 英中混用（Account / Beautify 等）、长 hint、`<pre>` 状态块、开关堆叠 → 信息密度高、情绪为零。
- 子页无统一模板：标题层级、留白、移动端钻取不一致。

### 0.2 输入流畅度

- 聊天 composer、人物设定、世界书、日记等表单样式与交互各自为政。
- 缺少「打字即反馈、少打断」：长文本无轻量自动保存提示；焦点 / 软键盘占位未统一。
- 主动消息、悬浮窗等旁路易抢注意力，削弱「在跟 TA 说话」的主路径。

### 0.3 近期迭代偏差

- 多轮改动偏「功能接线」（桌宠、读屏、导航合并），未同步做视觉与输入手感。
- 结果：功能似乎更多，但页面更难用、更不像给人用的产品。

---

## 1. 设计原则

1. **先主路径，再设置**  
   聊天输入 > 桌宠开关 > 「我的」里最高频 3 项（人物设定 / 日常行为 / 主题）。
2. **一屏一件事**  
   设置子页 = 中文大标题 + 一句人话说明 + 控件；砍掉开发者腔与冗余英文标签。
3. **好看服从品牌**  
   月栖纸感；少卡片、少调试块、少紫光 / 堆叠毛玻璃（遵循既有前端视觉规则）。
4. **输入不抢戏**  
   不弹无关气泡；保存用轻提示；移动端键盘不挡发送。
5. **每期可验收**  
   结束标准是「点得爽 / 打得顺」，不是「功能多了」。

---

## 2. 明确不做（本计划周期内）

- 不再并行大改衣橱 / 创作台 / 新运营入口。
- 不为「看起来功能全」加英文分区和终端风调试块。
- 不在「我的」塞模型 API Key（继续只在「接口」页）。
- 第 0–2 期不新增旁路主动能力（除非是降低打扰）。

---

## 3. 分期计划

### 第 0 期 · 止血（约 0.5–1 天）

| 项 | 做什么 | 验收 |
|----|--------|------|
| 停增 | 暂不新开旁路功能与多余浮层入口 | 无新的「突然冒出来」 |
| 入口 | 确认导航只有一个「我的」；默认路由选更高频项（账号或人物设定，定稿时二选一） | 进「我的」不懵 |
| 文案 | 目录与页头去英文标签噪音；hint 压到一行 | 扫一眼能懂 |

**出口**：不再继续扩大体验债务。

---

### 第 1 期 · 「我的」重做外观与信息架构（约 2–3 天）✅ 优先执行

**目标**：打开「我的」像个人中心，不像 CMS。

#### 3.1.1 重排目录（降认知负担）

**常用**

- 人物设定
- 日常行为
- 主题
- 语言

**数据**

- 记忆
- 云备份
- 账号

**进阶**

- 世界书
- 日记
- 日历与权限
- App / 小手机
- 更新
- 用户群

#### 3.1.2 统一子页模板

每个 `data-settings-view`：

1. 中文大标题  
2. 一句人话说明（≤ 1 行优先）  
3. 控件区  
4. 底部轻状态（状态行 / 短文案；**去掉大块 `<pre>` 终端风**）

#### 3.1.3 视觉

- 统一字号、间距、分割线与选中态。
- 目录选中清晰；移动端列表 → 详情过渡干脆。
- 行为开关改为干净的开关列表；账号 / 更新用状态行。

#### 3.1.4 验收

不看说明也能完成：

1. 改人物名  
2. 开关主动消息  
3. 换主题  

---

### 第 2 期 · 输入流畅度（约 2–3 天）

#### 3.2.1 聊天

- 统一输入框高度、焦点环、发送禁用态。
- 回车发送 / Shift+回车换行行为稳定、可预期。
- 软键盘顶起时 composer 不被挡；语音 / 附件不打断当前输入焦点。
- 流式回复时：输入区仍可编辑，或明确锁定并提供一键聚焦。

#### 3.2.2 「我的」长输入（人物底色、世界书、Prompt 等）

- 自动本地保存 + 「已保存」轻提示（无模态打断）。
- textarea 可拖高、字数友好。
- 世界书 / 标签编辑减少「点进再点进」。
- 表单统一 `edit-field` 视觉，禁止半套旧样式。

#### 3.2.3 验收

- 连续改人物设定约 1 分钟：不卡、不丢字。  
- 聊天连发约 10 条：手感顺、焦点不丢。

---

### 第 3 期 · 陪伴主路径手感（约 1–2 天）

- 聊天顶「桌宠」开关 / 悬浮窗「隐藏」/ 「我的桌宠」三处状态与文案一致。
- 截帧读屏、主动消息：默认安静；状态只在用户打开的面板里说清楚。
- 闲置主动（如心跳「想你了」）：默认可关、默认更克制，避免抢聊天主路径。

#### 验收

- 隐藏悬浮窗 → 用桌宠开关找回，路径 ≤ 2 步。  
- 聊天时不被无关推送频繁打断。

---

### 第 4 期 · 打磨与回归（约 1 天）

- 桌面宽度 + 手机宽度各走一遍：「我的」钻取、聊天输入、桌宠显隐。
- 勾掉「难受点」清单；未达标项不进入下一功能迭代。

#### 验收

- 核心路径无回归空洞页、双重「我的」、点了没反应的开关。

---

## 4. 建议执行顺序

```text
第 0 期止血
    → 第 1 期「我的」外观与架构（优先）
    → 第 2 期输入流畅度
    → 第 3 期陪伴主路径手感
    → 第 4 期回归打磨
```

功能类需求（新能力、新资产管线）排在本计划第 1–2 期之后，避免再次「功能进、体验退」。

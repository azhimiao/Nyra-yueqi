# 编辑能力与双壳界面改造

日期：2026-09-26。范围仅限商业版 `F:/beautiful`。不提交、不发布，不迁移用户聊天权威库。

## 交付顺序

1. Prompt：平台附加文案可选；角色、世界书、记忆等块可排序、启停、选择角色与注入位置；连接场景、示例、开场白和历史后指令；提供预设和实际请求预览。
2. 世界书：共享列表 / 详情编辑器，角色范围、关键词与组合触发、注入位置、预算、启停、导入导出真正作用于召回。
3. 记忆：按角色查看真实短期记录、共享记录、长期 / 核心 / 起源记忆；展示来源；可维护记忆的编辑、召回开关、删除同步作用于检索，保留原始聊天。
4. 外观与入口：App 与小手机使用同一编辑组件及持久化数据；设置分层，列表进入详情；主题、聊天字号 / 间距 / 气泡、卡片外观、小手机组件可预览、保存、还原。
5. 验证：首轮消息身份、Prompt 实际装配、记忆编辑删除后检索、世界书触发与预算、双壳导航与刷新；构建和相关静态门；浏览器 360 / 390 / 412 宽度视觉检查。

## 保持的边界

- Conversation V2 继续是聊天权威；不把 Prompt 示例伪装成真实历史。
- 开关控制产品附加给模型的自然语言规则；网关授权、账户与计费、工具执行校验、运行协议解析仍独立工作。
- 默认设置兼容当前行为。用户编辑不由默认关闭的实验 flag 决定是否生效。
- 角色与桌宠身份分离；保留现有脏工作树，不重置仓库。
- Node / 浏览器验证不作为 Android 真机、托管线上模型通过的证据。

# NYRA Chinese Copy Guide

中文产品文案保持月栖现有气质：**动态而克制**，像真人聊天，不像客服或广告。

## 产品名（冻结）

| 中文 | 英文 |
| --- | --- |
| 栖机 | Qiji |
| 栖机助手 | Qiji Assistant |
| 栖市 | Qiji Market |
| 朋友圈 | Moments |

中文界面始终使用「栖机 / 栖机助手 / 栖市」，不要写成「Qiji」混排。

## 要

- 短句、口语、留白
- 关系表达温暖但不煽情
- 按钮用明确结果：快速开始 / 认真认识一下 / 暂时跳过
- 品牌在中文界面用「月栖」

## 不要

- 客服口吻（“很抱歉给您带来不便”）
- 伪文艺堆砌与过度煽情
- 空泛词：智能化、赋能、沉浸式、全方位陪伴
- 生硬英译夹杂（“完成 Personality”“开启 Relationship Mode”）
- 把英文工具名硬译成「角色.检查」一类

## First Light

保持现有中文节奏；切换到英文 UI 时不得改写已保存的英文 ID 与用户答案。

## 错误

稳定 `code` + `t("errors.*")` 渲染，不把模型/后端不可控中文串直接当最终提示。

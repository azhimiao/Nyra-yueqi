## 每台设备步骤

1. 安装 debug / release APK（`npm run build:android`）
2. 角色页上传外表 → 确认 App 内浮层有图
3. 「去授权悬浮窗」→ 允许 → 返回 → 「开启悬浮陪伴」
4. 切换到微信 / Chrome，确认角色仍在
5. 点击角色：收起 → 气泡 → 聊天 → 收起
6. 下拉通知：返回月栖、关闭悬浮
7. 关闭悬浮后确认降级为 App 内浮层且文案诚实
8. （可选）从最近任务强杀后，记录是否需用户再次开启

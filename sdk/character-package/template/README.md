# Character Package Template

PAIOS P6 创作者角色包模板（本地导入 / 导出 / 私有分享）。

## 包含

- 身份、关系模式、边界、说话风格、价值观
- ≥6 动作、≥8 表情、口型 hooks、声音映射与同角色降级素材
- chat / task / waiting / success / failure 动作·语音映射
- 记忆策略与关系策略
- 多分辨率预览比例（桌宠 / Pop / App / 情景剧 / 通知）

## 不包含

- 系统权限、可执行入口、隐藏权限字段
- 公开商城、支付、广告、结算

## 使用

1. 复制本目录，替换 `assets/` 中的占位引用为真实透明底素材
2. 编辑 `character.json` 中的身份与策略
3. 用 Studio / `verify:core-p6` 跑一致性检查后本地导入

包升级**不会**覆盖用户关系记忆。
